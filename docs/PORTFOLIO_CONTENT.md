# Portfolio Content Checklist

Before publishing, verify each metric and separate public proof from confidential internal implementation details.

## Safe public themes

- Enterprise manufacturing analytics across production, inventory, pricing, and sales.
- Multi-schema production and pre-production SQL Server work.
- Near-live data refresh and automated reporting.
- React/Vite internal applications with Python APIs, authentication, validation, preprocessing, and caching.
- 80–90% automation with final human decisions retained for critical actions.
- Robotics, UAV, patent, competition, research, and team leadership work.

## Evidence to add later

- Sanitized screenshots with dummy data.
- Architecture diagrams.
- A public manufacturing analytics demo.
- Short case studies with problem, constraints, implementation, measured result, and lessons.
- GitHub repositories that demonstrate code quality without exposing employer intellectual property.
